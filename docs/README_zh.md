# SonGoten

**为创意酒吧而生的 AI 小游戏合集 —— 开源、自托管，只为好玩。**

[English](../README.md) · [简体中文](README_zh.md)

我们有个朋友，经营着一家很有创意的酒吧。我们想用 AI 给这样的地方带来更好的体验 —— 不是更聪明的收银系统，也不是站在门口的聊天机器人，而是一些让夜晚变得更有趣的小玩意儿。SonGoten 就是这个实验，并且完全开源：一组 AI 小游戏微服务，任何酒吧 —— 或者任何有一块屏幕、一张二维码的人 —— 都能在自己的机器上运行。

名字取自《七龙珠》里的**孙悟天** —— 那个把一切都当成游戏的小孩。

## SonGoten 是什么？

SonGoten 是一个开源的**酒吧小游戏微服务合集**。每个服务都是一个独立的小网页应用：客人用自己的手机打开它 —— 通常是扫一下桌上的二维码 —— 而店方只需要一台笔记本、一台迷你主机，或一台小小的服务器。

可以把它想象成一个装进酒吧里的游戏厅：

- **一个游戏，一个服务。** 每个微服务只把一件好玩的事做好，也可以完全独立运行。
- **带上你自己的手机。** 不用安装 App，客人的体验从二维码和浏览器开始。
- **AI 是主持人，不是噱头。** 大模型负责出题、扮演角色、即兴制造惊喜；而酒吧的气氛，仍然由真正的人来掌控。
- **默认自托管。** 你的酒吧、你的硬件、你的数据。
- **天生适合 Fork。** 每个游戏都小到一个下午能读完，一个晚上能改出自己的版本。

## 名字的由来

**孙悟天**是《七龙珠》里孙悟空的小儿子 —— 一个热爱游戏的孩子。他把修炼当玩耍，把每一个正经时刻都变成一场小小冒险。他不是故事里最强的战士，却是玩得最开心的那一个。

用他的名字，是因为我们想做一个「只为了好玩」的项目；也是向那部教会一代人「玩」与「长大」并不冲突的作品，认真地致个敬。

![热爱游戏的孙悟天](SonGoten.png)

*SonGoten 是一个独立的粉丝致敬项目，与《七龙珠》版权方无关联，也未获得其背书。《七龙珠》与孙悟天由鸟山明创作，相关权利归各自权利人所有。*

## 缘起

朋友的那家酒吧，酒好，音乐好，一屋子人却常常各自低头。

我们一直在想：如果 AI 在这样一个地方扮演的是**一位好客的主人**，而不是一名高效的员工，它会是什么样子？不是推荐算法，不是点单机器人，而是某种能让一桌人凑得更近、让陌生人开口打个招呼、让吧台后面的朋友会心一笑的东西。

我们想到的答案，是游戏。小小的那种，扫个码就能开始，冰块还没化完就能玩上一轮。

所以就有了这个项目：用 AI 做的开源小游戏，送给那些让夜晚值得被记住的酒吧，和那些让夜晚值得被记住的人。

## 游戏厅

第一批小游戏（BarAR 与 BarStreet 已可玩，其余仍在设计中）：

| 小游戏 | 玩法 | 状态 |
| --- | --- | --- |
| **BarAR** | 把手机对准十二星座鸡尾酒卡片，SARA 会从卡片里走出来，讲述这杯酒的故事。 | 已可玩 |
| **BarStreet** | 一条像素街区，Loopin、Citrus、HiJack、工厂四家酒吧。每天选一个岗位打工（调酒师、服务员、清洁工、酒水供应商），赚钱、集卡，集齐卡册到店换一杯真鸡尾酒。 | 已可玩（MVP） |
| **龙珠雷达** | 一场二维码寻宝：七颗「龙珠」藏在店里的各个角落，每颗都守着一道谜题。集齐七颗，酒吧替你实现一个愿望（通常是一份小吃）。 | 设计中 |
| **今晚什么味** | 在手机上轻点几下，AI 读出这一桌的心情，为它发明一杯鸡尾酒或无酒精特调的名字、一段小故事和一份配方。最终拍板的是调酒师。 | 规划中 |
| **吧台擂台** | AI 出题：关于你所在的城市、你喜欢的音乐、这条街的怪历史。大家用手机答题，一块屏幕计分。 | 规划中 |
| **歌词猎人** | 哼出来、打出来，或者唱得面目全非 —— AI 负责猜歌，并帮你把下一首排上。 | 规划中 |
| **祝酒词工坊** | 告诉它场合，它写一段像你说的话 —— 只是更好笑。举杯，念出来，然后让 AI 背锅。 | 规划中 |
| **午夜电台** | 酒吧的歌单变成一段深夜故事：AI 在歌曲之间讲述一个个短场景，整个店都成了听众。 | 规划中 |

> 你也有一个适合酒吧的小游戏点子？欢迎[提一个 Issue](https://github.com/JHerculesqz/SonGoten/issues)。唯一的要求是：它得能让一桌陌生人笑出来。

## 运转方式

每个游戏都遵循同一种简单的形态。

```
┌──────────────────────────────┐
│  客人的手机（任意浏览器）    │
│  扫码 → 打开小游戏           │
└──────────────┬───────────────┘
               │ 店内 Wi-Fi
               ▼
┌──────────────────────────────┐
│  SonGoten 微服务             │
│  一个游戏 · 一个容器         │
└──────────────┬───────────────┘
               │ OpenAI 兼容接口
               ▼
┌──────────────────────────────┐
│  你的大模型（本地或云端）    │
└──────────────────────────────┘
```

- **客人**只需要一个浏览器，不用注册，不用下载。
- **每个微服务**都是一个带着手机友好网页的小型 HTTP 服务，以容器方式交付。
- **AI** 可以是本地模型，也可以是云端服务，只要兼容 OpenAI 的对话接口。
- **店方**始终掌握主动权：开哪些游戏、AI 能说什么、一次会话持续多久，都由店方决定。

## 设计原则

1. **小即是美。** 一个游戏、一个服务、一个容器。如果一句话说不清楚，那它就太大了。
2. **手机是手柄，酒吧是舞台。** 游戏应该让人抬起头，而不是低下头。
3. **AI 是主持人，不是主角。** 如果一个游戏没有 AI 也好玩，那就保留游戏本身；AI 负责惊喜，而不是负责依赖。
4. **人始终拥有最后决定权。** 调酒师可以否掉一杯酒、一句台词，甚至整个游戏。员工永远不会被提示词取代。
5. **默认保护隐私。** 不注册、不追踪，今晚结束，数据就结束。
6. **便宜地运行。** 一家酒吧应该能用自己已有的硬件把它跑起来。
7. **负责任地好玩。** 每个饮酒游戏都提供无酒精路线，不劝酒。最好的夜晚，是每个人都安全到家。

## 如何开始

BarAR 与 BarStreet 现在都可以运行。Docker 构建时会从 GitHub master 拉取两个前端，再打包
`Backend/` 中的 FastAPI 服务：

```bash
git clone https://github.com/JHerculesqz/SonGoten.git
cd SonGoten/Backend
cp .env.example .env      # 可选：端口、加速镜像、店员 PIN
docker compose up -d --build
```

打开 <http://本机IP:3501/octogame/barar/> 看 SARA 从卡片里走出来，或打开
<http://本机IP:3501/octogame/barstreet/> 在 Loopin 上第一班、开始集卡。
详细说明见 [BarAR/README.md](../BarAR/README.md)、[BarStreet/README.md](../BarStreet/README.md)
与 [Backend/README.md](../Backend/README.md)。

## 参与贡献

欢迎贡献 —— 尤其是那些小小的、古怪的、让人会心一笑的贡献。

- **有游戏点子？** 提一个标题为 `[Game] ...` 的 Issue，描述它想在一桌人之间制造的那个瞬间。
- **想动手做一个？** 保持单一微服务，附上 README，并确保它不依赖项目里的其他服务也能运行。
- **唯一的要求：** 它得好玩 —— 对一桌陌生人来说好玩，而不只是对拿着手机的那个人好玩。
- 保持友善。酒吧是一个共享的房间。
